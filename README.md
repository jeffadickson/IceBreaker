# IceBreaker

Offline-first hockey scorekeeping, live parent game tracking, league scheduling, standings, statistics, and tournament management.

**Status:** Repository initialized. The complete application source has not yet been uploaded to GitHub. Do not treat this repository as the full release.

## Components in the prepared local package

- Rink scorekeeper: goals, assists, penalties, TBD attribution, clock, mercy rules, and complete operator audit logging.
- Live parent tracker: read-only full official score and play-by-play, independent of arena mercy score cap.
- League website: teams, schedules, player statistics, standings, and certified results.
- SQLite / Node.js local backend and C# game engine prototypes.
- HTML user manuals, requirements, tests, and GitHub CI.
- Proposed remote certification workflows, authenticated signing, parent accounts, favorites, and end-of-game reports.
