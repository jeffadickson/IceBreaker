Team manager game procedures

Configurable, auditable checklists for exhibition, tournament, and league games

Prototype status: The policy file and checklist projection library are implemented and tested. This page explains the intended process; checklist saving, team-account permissions, and automatic external-portal uploads are not yet integrated. Validate current league rules and deadlines before use.
EXHIBITION

Before and after

  1. Request referees: Scrimmage@lahoa.com
  2. Add game in the Managers Portal
  3. Verify approval/notification requirements
  4. Record game on a scoresheet
  5. Upload final sheet and retain submission confirmation
TOURNAMENT

Before and after

  1. Add tournament in Managers Portal
  2. Add each tournament game
  3. Verify sanction/notification requirements
  4. Record every game on a scoresheet
  5. Collect and upload signed copies
LEAGUE GAME

Game day

  1. Update jersey numbers; assign participating coaches
  2. Print scoresheets and confirm active roster
  3. Obtain participating coaches' signatures
  4. Cross off nonparticipating players and coaches on all sheets
  5. Upload signed sheet and complete league statistics entry

Evidence-first workflow

Each task requires a reference such as a roster revision, referee booking email ID, signed scoresheet, submission receipt, or external portal confirmation. A completed task can be reopened without erasing its audit history. Each game is bound to a particular workflow policy version.

The machine-readable profile is config/workflows/scaha-manager.json; validation and projections are in src/team-workflows/manager-checklist.js.

Scoresheet and deadline references

SCAHA's Manager Tools page contains a Download link for a blank exhibition scoresheet. Use the current official copy. The 2025–26 SCAHA guidebook describes a 10 p.m. following-Monday submission deadline for league games; check the current season's guidebook before configuring reminders.
