Try the existing browser interfaces

Install Node.js 22.13+ and launch node apps/rink-local/server/rink-server.js from the repo root. On the same computer browse http://127.0.0.1:8090/operator.html, /live.html, and /league.html. The server binds to localhost by default. It is not safe for public deployment.
