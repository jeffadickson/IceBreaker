ICEBREAKER / QUICK START

Quick start

Run only on a development machine; this is not a public production deployment.

Prerequisites

  1. Windows, macOS or Linux with Node.js 22.13+ installed (Node's node:sqlite is experimental).
  2. Optional .NET 8 SDK to run the C# tests; .NET was not verified in the original build environment.
  3. Python 3 for documentation checks.

Launch

node apps/rink-local/server/rink-server.js

Then open:

  • Operator scoring console
  • Parent live tracker
  • League Center

Exercise the complete prototype flow

  1. Open the operator and parent pages in separate browser tabs.
  2. Record a home-team goal; choose TBD for unknown assists, inspect the draft, and confirm.
  3. Verify the goal appears in parent Live without refreshing.
  4. Record a penalty and advance the period; verify the timeline.
  5. Restart the local server; verify committed events persist and the clock is recovered stopped.

Test

node --test apps/rink-local/tests/browser/*.test.js
python tools/check_docs.py
dotnet test apps/rink-local/tests/Icebreaker.Core.Tests/Icebreaker.Core.Tests.csproj

Node tests must be run in a Node installation supporting the experimental SQLite module; do not assume the C# project is compiled until tested locally.
