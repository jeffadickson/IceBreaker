ICEBREAKER / SECURITY & PRIVACY

Security and youth privacy

Public deployment is prohibited for the current prototype. It has an intentionally simple shared development credential and no production station enrollment or parent authentication.

Required roles

RoleAllowed
ScorekeeperOperate assigned game's commands and submit provisional events
Assigned refereeReview/sign exact assigned game snapshot
League administratorManage rosters and adjudicate with full audit
ParentRead permitted content, follow teams/players, opt in to reports
Public spectatorRead permitted public full-score projection only

Controls

  • Private asymmetric station keys, rotation/revocation and game assignment.
  • Transport security, authentication/MFA for elevated roles, strong session lifetime rules.
  • Least-privilege data projections and server-side authorization; no client-trusted role flags.
  • Verifiable guardian relationship for guardian-only youth information.
  • Retention/consent controls, restricted PII in audit logs, no secrets in telemetry.
  • Throttling, CSRF defenses where applicable, webhook validation, delivery abuse prevention.

Signing

Electronic scoresheet approvals must represent explicit signatory intent, approved identity, immutable snapshot digest, and applicable retention/legal review; do not present as equivalent to general DocuSign legal signing by default.
