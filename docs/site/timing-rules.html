GAME OPERATIONS

Division timing rules, warm-ups, and breaks

Game timing belongs to a division-specific, versioned ruleset. A 10U A division can use different periods, warm-ups, and intermissions from 10U BB or 10U B.

Configuration

Authorized development administrators can use /division-rules.html to set the regulation period count and duration, warm-up length, intermission length, and a reserved overtime duration. All values are integer seconds internally, and legal ranges are validated server-side.

SettingSupported rangeDefault demo value
Regulation periods1–93
Period length60–3600 seconds15:00
Warm-up0–3600 seconds5:00
Intermission0–3600 seconds2:00
Overtime (reserved)0–3600 seconds0:00

Values outside the configured period range, including negative game time, are rejected. Advancing beyond the configured final regulation period is rejected. The rink authority pins the version and JSON timing policy with its game journal; a restart cannot silently load a different policy.

During the game

Open the rink operator screen. The timing panel displays the active division policy and provides Warm-up, Intermission, Start break clock, and Pause controls. These operate a separate timer; they do not decrement the game clock or penalties.

The auxiliary timer records its start, pause and reset actions in a durable SQLite history and the private operator audit. After a crash, a running auxiliary timer recovers stopped at the last committed value, rather than silently counting during downtime.

Rink scoreboard synchronization

For a small correction, stop the official game clock and press ▲ +1s or ▼ −1s. These adjust game and active penalty timers together by default. For an independent correction, use Set arena time; this changes only the game clock. A correction to an already-completed penalty still requires an authorized referee decision.

Rule changes and releases

Changing a live or finalized division's rules in place is prohibited. Rulesetting controls use a development administrator key; production administrator identity and delegated permissions remain release work. The configured overtime length is presently metadata; automatic overtime phase management and league-specific overtime rules are not implemented.

Verification

Run node --test apps/rink-local/tests/browser/division-timing-rules.test.js apps/rink-local/tests/browser/auxiliary-clock.test.js. These cover time bounds, default/pinned rules, auxiliary recovery, and division administration permissions. The full regression suite runs in GitHub Actions.
