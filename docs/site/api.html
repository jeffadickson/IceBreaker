Verb / pathPurposeAccess

GET /api/games/demo/snapshotFull-score spectator projectionLocal read-only

GET /api/league/v1/overviewLeague viewLocal read-only
POST /api/league/v1/gamesCreate scheduled gameDevelopment operator key

Do not put the shared operator key in distributed production browser JavaScript. Production requires per-user and per-device identities, central authorization and HTTPS.
