Parent accounts and Google sign-in

Parents can create an account, verify their email address, sign in, follow teams or players, and choose end-of-game email preferences. This is a local development implementation, not yet a public-ready identity service.

Try it locally

Start npm start from the repository root and open http://127.0.0.1:8090/parent.html. Register using a password of at least 12 characters. In the development SQLite database, a verification message is queued in parent_mail_outbox. An email sender has not yet been connected, so real inbox delivery does not occur.

Enable Google login

  1. In Google Cloud Console, create or select a project and configure an OAuth consent screen.
  2. Create an OAuth client of type Web application.
  3. Add the authorized redirect URI http://127.0.0.1:8090/api/parent/google/callback for local development. For hosting, use the corresponding HTTPS URI.
  4. Set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and ICEBREAKER_PUBLIC_URL as environment variables; never commit their real values.
  5. Restart the backend and select Continue with Google on the parent sign-in page.

IceBreaker verifies the returned Google ID token and creates an account keyed by Google's immutable sub identifier. If the email already belongs to a password account, the system refuses automatic linking. A separate verified linking workflow will be added.

Identity and privacy rules

Parent favorites do not grant roster-management or private player data permissions. Public youth profiles and reports will require explicit guardian controls, opt-outs, retention rules, and privacy review before deployment.

Implementation limits

Automated certified-game reports and SMTP/provider delivery are not implemented yet. Parents can save report preferences, but no email report is sent.
