ICEBREAKER / PA ANNOUNCER

Automated public-address announcer

The game-event engine may plan announcements for goals, penalties, period ends, the last minute, and official attribution corrections.

Operator flow

  1. Enable announcer and choose local offline or optional cloud voice.
  2. Choose manual-approval or approved auto-play policy.
  3. Review pronunciation, number-only youth privacy rules, speaker destination and volume.
  4. Preview privately, then broadcast on the arena PA output.

Example

“Pasadena goal! Scorer and assists to be announced.”

After attribution confirmation, the system can announce a correction without replaying the original goal horn.

Safety and failure behavior

PA speech is downstream of official game state; a TTS outage must never affect scoring. Recovered pending announcements require operator review so a stale goal is not broadcast following a crash.

The prior C# work includes announcement planning/outbox interfaces, but actual sound generation, mixer output and hardware certification are not implemented.
