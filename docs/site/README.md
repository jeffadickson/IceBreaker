# IceBreaker documentation site

Open `index.html` directly in any modern browser; navigation and page content work without a server. Search indexing uses `fetch` and may be unavailable under browser `file://` restrictions; for full search run `python -m http.server 8000 -d docs/site` and open `http://127.0.0.1:8000`.

This site contains implemented behaviors and proposed requirements, clearly distinguished. The existing UI is under `apps/rink-local/web/`.
