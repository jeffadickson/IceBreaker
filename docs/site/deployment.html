ICEBREAKER / OPERATIONS & DEPLOYMENT

Deployment and operations

Local demonstration

Launch on a workstation using node apps/rink-local/server/rink-server.js. Default binding is loopback, port 8090. Keep private database files and logs outside version control.

Backups and resilience

  • Keep independently stored encrypted backup copies of the journal and certified revisions.
  • Alert operators immediately if audit/log mirroring fails; protect official game continuity.
  • Use SQLite WAL and controlled backups; never copy a live database without a consistent snapshot.
  • Recover game clock stopped and require operator review of queued announcements.
  • Rebuild projections from committed source events; reconcile remote outbox before final approval.

Production prerequisites

  1. ASP.NET Core production API with authenticated rink station registration and remote synchronization.
  2. Central hosted database with migrations, RBAC, secret manager, HTTPS and observability.
  3. Official approval workflow and revocation-safe device identity.
  4. Parent login, privacy controls and monitored email provider.
  5. Threat model, load tests, crash injection, browser E2E and hardware certification.
No production deployment manifests are included because the current authentication model is deliberately development-only.
